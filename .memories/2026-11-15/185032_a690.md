## Kick API compatibility work: phase 1 (core) delegated

**What:** Compatibility sweep (2026-11-15) against Kick's spec (`api.kick.com/swagger/doc.json`) and KickDevDocs found the SDK covers 7 of 34 operations; Livestreams v1 deprecated (2026-06-23).

**How (decisions):**
- Phase 1, 4 parallel Opus 5.5 subagents in the shared checkout, disjoint file ownership:
  - `oauth.rs`: user OAuth with PKCE (high)
  - `public_api.rs` + `http.rs`: livestreams migration and reads (high)
  - `public_api/*.rs`: user-token actions (high)
  - `webhooks.rs`: 3 typed events (medium)
- `Endpoints.api` becomes `https://api.kick.com`; every path carries `/public/v1` or `/public/v2`.
- PKCE verifier and state come from caller-supplied CSPRNG bytes, keeping the core sans-IO and wasm-safe.
- No recordings are possible without credentials, so documented examples go in `fixtures/docs/**` (README says transcribed from docs) and KICK.md marks those claims *(docs)*.
- `parse_livestreams` reads both the v1 recordings and the v2 shape; `Sort` is removed (v2 has no sort).
- Docs snapshot is at `/tmp/kickdocs/raw/` (ephemeral).

**Rejected:** worktree-per-agent (would drop the uncommitted audit fixes and every feature touches dispatch/bindings); one serial agent (slow).

**State:** working tree also holds the uncommitted audit fixes from earlier the same day.
